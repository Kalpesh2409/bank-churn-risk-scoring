# Bank Customer Churn: Predictive Modeling and Risk Scoring

A machine learning project that predicts which bank customers are likely to leave,
assigns each a churn probability (0 to 1), and explains why.

**Status:** In progress (Data Analyst Internship, Unified Mentor)

## Planned Deliverables
- Research report (EDA, modeling, insights, recommendations)
- Interactive Streamlit dashboard (risk calculator, what-if simulator)
- Executive summary for bank business stakeholders
